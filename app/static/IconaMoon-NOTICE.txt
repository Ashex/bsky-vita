IconaMoon 1.1 Color icons

Source: IconaMoon, https://github.com/ (local source directory: /home/evelyn/git/icons/IconaMoon/SVG/Color)
The IconaMoon README describes the icon library as “totally free and you can do whatever you want with it.” This project bundles four rasterized icons (Synchronize, Arrow Left 1, Arrow Right 2, Close) from the Color style. The atlas is generated by tools/build-pocket-icons.py. No Streamline assets are used.

Attribution: IconaMoon / Dariush, IconaMoon 1.1. Source README: https://www.figma.com/@dariush and https://www.redl.ink/dariush.
